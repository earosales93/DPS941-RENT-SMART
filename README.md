# DPS941-RENT-SMART
RENT SMART es una solución multiplataforma desarrollada para Rosales Rent A Car, una empresa salvadoreña de alquiler de vehículos que opera desde 2022. El proyecto surge de un diagnóstico concreto: de los ocho pasos que componen el ciclo de alquiler de la empresa, seis dependen de una acción manual y cinco no dejan ningún registro digital.
